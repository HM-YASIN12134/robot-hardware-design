# Robot Hardware Design (PCB & Power Systems)

## 🛠️ Description
This repository will contain the hardware schematics, PCB designs, and power management systems for the autonomous robot.

## 🔗 Integration with Existing Repositories
- **`electronics-from-scratch`:** This is the **direct parent repository**. The voltage regulator designs, MOSFET H-bridge circuits, and Op-Amp signal conditioning learned there will be physically implemented here.
- **`esp32-diy-radar-system`:** The ESP32 microcontroller and radar circuitry will be integrated into this main hardware board.

## 📝 Design Goals
- Custom PCB design for the main control board.
- Efficient thermal management for motor drivers (Applying heat sink calculations from `electronics-from-scratch`).
- Noise filtering using RC and LC circuits (Applying knowledge from `electronics-from-scratch`).
